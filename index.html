Browser-based utilities

SDD Tools

A collection of lightweight, client-side tools for everyday developer tasks. Everything runs in your browser — no data leaves your machine.

⚖️

Field Drift

Compare two JSON exports of the same records. Entries are matched on id, fields are paired by name, and each pair is checked value by value.

JSON · Reconciliation
⚖️

Key Hoist

Turn a JSON object-of-objects into an array, moving each key inside its own object as an id field. Same transform as the script, in the browser — nothing is uploaded anywhere.

JSON · Reshaping
📝

Diff Viewer

Load a .diff or .patch file and browse changes in a side-by-side view with a navigable file tree and syntax highlighting.
